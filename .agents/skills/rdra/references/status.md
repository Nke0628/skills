# 状態の報告(引数なし)

目的: 今どこにいて、次に何をすればいいかを伝える。書き込まない。

## 手順

1. git リポジトリでなければ、「判断の履歴を残すため git init してよいか」を一度だけ確認する。断られたら、差分の検出ができないことを伝えて続ける。
2. `docs/rdra/` がなければ `rdra.py init` を実行し、次のように案内して終わる。
   - 議事録や参考資料があれば `docs/rdra/inputs/` に置いて `/rdra draft`(初期要望の下書きを作る)
   - なければ `docs/rdra/初期要望.txt` を書いて `/rdra phase1`
3. `rdra.py status` を実行し、次を短く報告する。
   - 現在のフェーズ、仮説の行数、質問の件数(優先度・高の未解決を強調)
   - 次の判定を満たしているか。満たしていなければ主な理由を3件まで
   - 次にやること(例: 「questions.html で優先度・高の3問に回答して `/rdra apply`」「条件を満たしたので `/rdra phase2`」)
